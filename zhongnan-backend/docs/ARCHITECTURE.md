# 终南编剧AI · 后端技术架构方案 v0.1

> 目标：让前端 v0.95.x 的所有“真金白银”环节真正跑起来——真实模型调用、积分扣费、会员支付、海报出图、邀请结算、工单入库。

## 1. 技术选型
| 层 | 选型 | 理由 |
|----|------|------|
| 运行时 | Node.js 20 + TypeScript | 与前端同语言，团队一套技术栈 |
| 框架 | Express（本骨架）→ 规模化可迁 NestJS | 轻、上手快；模块边界已按 controller/service/repo 分层 |
| 主库 | PostgreSQL 16 | 事务可靠、JSONB 存圣经/质检报告 |
| 缓存/队列 | Redis + BullMQ | 会话、限流、生成任务队列、SSE 进度 |
| ORM | Prisma | 见 `prisma/schema.prisma` |
| 鉴权 | JWT + Refresh 轮换，argon2 哈希 | 手机号/微信/抖音登录 |
| 支付 | 微信支付 + 支付宝 | 下单/回调/对账/退款 |
| 对象存储 | 阿里云 OSS / 腾讯 COS | 剧本、海报、截图 |
| 部署 | Docker + 阿里云 ECS/ACK + RDS | CI/CD：GitHub Actions |
| 可观测 | Prometheus+Grafana / Sentry / ELK | 成本、毛利、错误监控 |

## 2. 模块划分（按里程碑）
1. 认证用户（注册/三方登录/RBAC）
2. 会员/订阅（level+expireAt 由 Membership 派生）
3. **积分账本**（复式流水，见下）
4. **创作编排**（六岗位+双校验管线，SSE 流式）
5. **模型代理网关**（黑盒+成本+毛利熔断）
6. 订单支付（充值/会员/增值，回调幂等，对账）
7. 增值服务（海报/PK/小南/质检/分镜）
8. 邀请裂变（关系链、奖励、永久分成结算）
9. 社区/交易/担保
10. 反馈工单、后台、内容安全

## 3. 不赔钱的积分账本（核心）
- **账户 + 复式流水**：`PointsAccount` 余额是流水物化结果；每笔变动写 `LedgerEntry`，带 `idempotencyKey` 幂等键，可对账可回溯。
- **冻结-结算-解冻**：生成任务先 `freeze` → 成功 `settle` 实扣 / 失败 `unfreeze` 退回，绝不让用户为失败买单，也绝不“做了不扣”。
- **赠送分桶 + 上限**：赠送积分 BONUS 桶、90天有效、FIFO 核销；单用户累计赠送 ≤300 分（真实成本 ≤3.3 元），超出必须付费/邀请。
- **价格服务端定**：前端只传服务 key，价格/成本只在 `config/pricing.ts`；启动时 `assertNoLoss()` 校验每项 **售价 ≥ 成本×2**，违反直接拒绝启动。
- **真实成本回写**：每次模型调用写 `ModelCallLog`（tokens/张数/成本/计价），毛利跌破阈值实时熔断告警。

## 4. 模型黑盒代理（保密 + 防绕过）
- 前端只调 `/api/generate`，只传**引擎档位**（经济/标准/旗舰），永不出现供应商、模型名、密钥。
- 服务端 `model-proxy.ts` 把档位映射到真实模型，密钥从环境变量/KMS 读取，**绝不下发前端、不进 Git**。
- 统一超时/重试/降级；图片按张计成本（旗舰约1.4元/张），4选1成本×4，售价已保2倍毛利。

## 5. 创作管线
`dispatcher → 架构师→人设师→撰写师→润色师→合规→市场 → 一致性校验+去AI化校验（不过打回，最多2轮）→ 成稿质检闸门`
- 全局 `Bible`（世界观/人设/时间线/伏笔）贯穿全程，解决多集断层。
- SSE 推送岗位状态（用户看到团队协作，看不到模型）。
- 成稿后过 `final-qc-gate`：字数(800-1000/1200-1500)、格式、元话语、钩子、AI痕迹正则，全绿才“可交付”。

## 6. 关键接口（首批）
- `POST /api/auth/*` 注册登录
- `POST /api/generate/episodes`（SSE）创作一集，含计费闭环 ✅本骨架已演示
- `POST /api/generate/consume/:key` 增值服务消费 ✅
- `POST /api/order/*` 下单/支付回调
- `POST /api/feedback` 反馈/Bug工单 ✅
- `POST /api/poster`、`/api/pk`、`/api/invite/*`

## 7. 安全合规
- 密钥 KMS 加密、密码 argon2、JWT 短时效；接口限流防刷；敏感词三级审核；
- 用户内容版权承诺、侵权风险提示；数据异地备份、最小采集。

## 8. 部署成本（小规模起步估算）
ECS×2(4C8G)≈300 + RDS PostgreSQL≈400 + Redis≈100 + OSS/CDN≈80 + 备份/监控≈100 ≈ **1000-1500 元/月**，随用量弹性；模型 API 为变动成本，已被售价×2覆盖。

## 9. 落地里程碑
- **M1（2周）**：认证 + 积分账本 + 模型代理 + 创作闭环，能真实生成并扣费
- **M2（2周）**：微信/支付宝支付 + 会员 + 增值服务
- **M3（2周）**：邀请裂变 + 社区 + 剧本交易担保
- **M4（1周）**：后台 + 合规 + 监控压测，灰度上线

## 10. 本地运行
```bash
cp .env.example .env       # 填数据库/密钥
npm install
npm run db:push            # 建表
npm run dev                # http://localhost:8080/health
npm run typecheck          # 类型自检
```
> 当前 `InMemoryTx` 可在不连数据库时验证计费闭环；生产替换为 `PrismaTx`（行锁 + 事务）。
