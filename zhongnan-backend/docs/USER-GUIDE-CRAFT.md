# 小南递招 · 用户操作指引

> 覆盖两条路径：**独立递招**（从一句话创意起步）与**标签台联动**（先定标签，再顺手拿手法）。
> 文档基线：v2.677.0。界面文案以简体中文为准，英文界面按钮名在括号内给出。

---

## 一、先分清两条路径

| | 独立递招 | 标签台联动 |
| --- | --- | --- |
| 从哪里进 | 顶栏「递招」 | 首页「标签创建」或 创作 → 标签创建 |
| 你手上已有什么 | 一句话创意，可能还有开篇几句 | 一组标签，可能还有一句补充创意 |
| 小南读什么 | 只读递招面板里的一句话创意 + 开篇试写 | 只读标签 + 标签台的补充创意；有打开中的作品时，读作品正文做开篇审计 |
| 出本时带什么 | 创意 + 选中手法，按**自动匹配**模式出本 | 标签 + 补充创意 + 选中手法，按**标签模式**出本 |
| 适合谁 | 脑子里只有一个画面，还没想好题材标签 | 已经知道要什么赛道，想快速定向出本 |

两条路径的输入互不串用：独立递招不会偷偷带上标签台的标签，标签台也不会读递招面板里的底稿。这样你上一次试验留下的内容不会污染这一次。

## 二、路径 A：独立递招（从一句话创意起步）

### 第 1 步：打开面板

顶栏点「递招」，出现「小南递招 · 方法卡与钩子」面板。面板顶部会先给一套默认钩子组合，这是兜底，不是最终答案。

### 第 2 步：写一句话创意

在「一句话创意」（`#craftIdea`）里写清三件事，匹配会明显更准：

1. **谁**：主角身份，例如「被顶替名额的女医生」。
2. **反常事件**：打破日常的那一下，例如「回乡竟查到自己的死亡证明」。
3. **悬念方向**：读者想追下去的问题，例如「是谁在替她活着」。

输入上限 160 字。写不满没关系，但只写「复仇」「逆袭」这类大词，匹配会退回到通用钩子。

### 第 3 步（选填）：贴开篇试写

把已经写好的开场几句贴进「开篇试写」（`#craftOpening`）。系统只读取前 300 字做审计，输入框最多容纳 1200 字。

- 只写一句也可以，审计会指出「还缺哪些关键钩」。
- 不贴也能递招，只是没有开篇审计这一段。

### 第 4 步：点「按当前创意递招」

按钮文案为「按当前创意递招」（英文界面 `Suggest for this idea`）。等待时面板会显示「小南正在匹配最贴的钩子与方法…」。

> 这一步免费，不消耗积分。推荐由本地规则库计算，同样的输入会得到同样的结果，便于对照修改。

### 第 5 步：读三块结果

**① 钩子区**：系统给出基础钩子（每集钩、每场钩、连环钩）加上按你的创意匹配出的钩子。钩子决定「观众为什么往下看」。

**② 方法卡区**：最多 6 张「最贴你创意的方法」，下面还可以展开全部方法卡库。每张卡点开后能看到公式与步骤，例如「先抑后扬」的具体做法。

**③ 开篇审计**（贴了开篇才有）：告诉你前 300 字已经用了哪些钩、下一处该往哪里发力。它只判断钩子结构，不评价文采。

### 第 6 步：增删与挑选

- **移除钩子**：点钩子右侧的 ×。
- **增选钩子**：用「增选钩子」下拉框挑一个加入。
- **点选方法卡**：卡片头部显示「点选」，点一下变为「已选 ✓」，再点一下取消。
- **搜索方法卡**：在搜索框输入关键词（如「反转」「误会」），结果只来自全量卡库，不会和推荐区重复。
- **复制手法**：点「复制手法」，得到一行可直接粘贴的文本，例如「创作手法：钩子[每集钩、反常钩]；方法[先抑后扬]」。

你选中的钩子与方法卡会记在这台设备上，下次打开仍然在。换设备或清浏览器缓存后需要重选。

### 第 7 步：出本

选好手法后，直接去「创作」选模式并点生成即可。有两个细节需要知道：

1. **递招面板展开时启动生成，会按「自动匹配」模式出本**，标题取一句话创意的前 40 字，简报由「一句话创意 + 创作手法」组成。
2. 如果先关掉递招面板、再在某个具体模式里写简报，手法同样会追加到简报末尾（简报里已有同一行时不会重复）。

出本后，九大岗位读到的是同一份带手法的简报，不会各写各的。

### 改输入之后会发生什么

| 你改了什么 | 立即失效 | 仍然保留 |
| --- | --- | --- |
| 一句话创意 | 旧推荐方法卡、面板里的旧审计 | 已选钩子与已选卡（可继续用，也可重新递招） |
| 开篇试写 | 开篇审计 | 钩子与方法卡 |
| 点「按当前创意递招」 | 全部替换为本次新匹配 | 无，手动增删过的选择也会被替换 |

最后一行是刻意设计：每次递招都按当前输入重新给一套完整方案，避免新旧手法混在一起。**想保留手动挑的组合，就先别重复递招，直接出本或先复制手法。**

## 三、路径 B：标签台联动（先定标签，再拿手法）

### 第 1 步：进入标签台

首页「快捷创作 → 标签创建」，或 创作 → 标签创建。第一次进入且没有已选标签时，系统会自动随机一组，做到打开就能用。

### 第 2 步：把标签调到你满意

- **🎲 智能随机一组**：按你的长期偏好给一组，最多 8 个。
- **🧩 补齐维度**：在现有标签基础上补空缺维度，不推翻已选。
- **换一批**：重新随机一组。
- **搜索标签**：输入「穿书」「文旅」「复仇」等关键词，从标签池里挑；也可以按维度筛选。
- **移除标签**：点已选标签上的 ×。
- **清空**：一次清掉全部标签，回到空白状态。

手动增选最多 14 个标签。标签下方会显示小南给出的推荐理由，说明这组标签为什么适合当下市场。

### 第 3 步：看「小南随标签递上的手法」

每次随机、换一批或手动重新递招后，标签台里会出现一块「小南随标签递上的手法」（v2.676 新增）：

- **钩子**：这组标签最该用的钩子。
- **方法卡**：最贴的几张方法。
- **开篇审计**：如果当前打开着一部作品，会读作品正文前 300 字，指出已经用了哪些钩、下一步往哪发力。没有打开作品时，这一行不出现。

这块是只读摘要，方便你在一屏内判断「这组标签 + 这套手法」是否成立，不用来回切面板。

### 第 4 步：需要时手动重新递招

改完标签或补充创意后，点回显块右上角的「按当前标签重新递招」。手选标签也能主动重算，不再只能靠随机触发。

### 第 5 步：出本

点「下一步：生成剧本 →」（`#tagGoBtn`）。出本简报由三部分组成：

```
标签组合：女频、逆袭、乡土、复仇…
一句话创意：被顶替名额的女医生回乡逆袭
创作手法：钩子[每集钩、反常钩]；方法[先抑后扬]
```

这三个部分会一起进入项目简报，后续大纲、逐集、体检都基于同一份上下文。

### 回显什么时候失效

以下动作会让旧回显失效，避免你拿上一次的旧手法出本：

- 增删标签；
- 清空标签；
- 修改补充创意；
- 切换界面语言（旧语言的名称不再适用）。

失效后回显块不会消失，而是变成虚线边框并提示「标签或创意刚改过」，原来的钩子与方法卡撤下，右上角的「按当前标签重新递招」仍然可点。点一次即可换成新结果。这样你不会因为标签一变就失去重算入口。

## 四、结果怎么读

### 钩子

钩子解决「为什么继续看」。三类基础钩固定出现：

| 类型 | 作用 |
| --- | --- |
| 每集钩 | 这一集结尾留什么，让观众点下一集 |
| 每场钩 | 这一场戏内部靠什么抓住人，避免平铺直叙 |
| 连环钩 | 多个悬念如何接力，撑住中段不塌 |

其余钩子按创意或标签匹配补入，例如「反常钩」「身份钩」「倒计时钩」。

### 方法卡

方法卡是可直接执行的写法，不是形容词。每张卡包含：

- **公式**：一句话结构，例如「先抑后扬 = 先让主角失去，再给出反击」；
- **步骤**：按顺序可照做的动作；
- **适用场景**：什么桥段适合用。

推荐区最多 6 张，全部卡库可展开浏览或搜索。卡库数量会随版本增加，面板顶部显示的是当前真实总数，不是写死的数字。

### 开篇审计

审计只看前 300 字，输出两件事：

1. **已经钩住**：识别到的钩子名称；
2. **下一步**：还缺哪种钩、下一句该往哪发力。

它不判断文采、不判断对错，也不替代人工围读。贴的开篇超过 300 字时，后面部分不参与审计。

### 出本后的下一步（v2.677）

生成完成停在结果页时，最下方有一条「下一步」交接条，两个出口都直连当前项目：

| 出口 | 点下去发生什么 | 适合谁 |
| --- | --- | --- |
| 查看全部分集与版本 | 切到作品库并直接打开这部剧的详情：分集列表、历史版本、单集体检、全本诊断都在那里 | 想回头改第 3 集、或对比两版差异 |
| 继续写第 N 集 | 带着这部剧的设定、人物与当前进度回到创作台，集数自动落到下一集 | 想顺着往下写，不想重新填一遍简报 |

- 只有已经存在至少一集正文时交接条才出现；沙盘无正文或项目未落库时自动隐藏，不占版面。
- 两个按钮点击期间会置灰，防止重复请求；打开失败会给出提示并恢复可点，不会扣积分。
- 作品详情里的「继续创作」「单集体检」「版本对比」仍然保留，交接条只是把它们提前到结果页，不替代原入口。

### 单集体检：带着出处去，看完回得来（v2.678）

在作品详情里点某一集的「剧本体检」，体检面板顶部会出现一条金色来源条：

| 你会看到 | 含义 | 点「回到该集」会怎样 |
| --- | --- | --- |
| 来自《剧名》· EP3 | 这轮体检的正文来自哪部作品的第几集，多集交替体检也不会串 | 关闭体检面板，平滑滚回第 3 集卡片并短暂描金高亮，直接接着改这一集 |

- 只有从作品库分集进入时才显示来源条；从工具箱或结果页「送进体检」进入时不显示，避免把上一轮的出处带到无关正文上。
- 来源条只是标记，不改体检结论；体检本身仍然免费、不耗积分。
- 想换一集体检：关掉面板回到分集列表，点另一集的「剧本体检」即可，来源条会随新入口刷新。

**分集卡片怎么读（v2.679）**：每集卡片是「标题一行、操作一行」。上一行是 `EP3 · 标题` 加版本与字数，下一行是「对比 / 听剧本 / 剧本体检 / 复制本集正文」。手机窄屏会自动改成上下两行、四个按钮等宽铺开，不再挤在标题里；英文长标题在窄屏会换行显示，不会被截掉。手机上如果顶栏按钮放不下，左右滑动即可，账号按钮排在控件区最前、始终先看到。

### 素材库：先看来源，再看授权（v2.680）

- 面板顶部那行「收录范围与授权说明」默认收起，点一下才展开完整说明；手机首屏直接看到来源卡片，不用先滑过一大段法务文字。
- 语言筛选在手机上是一行横滑：左右滑动挑语种，右缘渐隐代表后面还有；桌面端自动换行铺开。
- 英文界面下，公版徽标显示 `Public domain`、多语筛选显示 `Multi`，不再出现 `PD` 缩写或中文「多语」。
- 搜不到或筛过头时会出现「清除搜索与筛选」按钮：一次清空搜索词、取消「只看可直接改编」、回到全部语种，不用逐项手动撤销。
- 说明胶囊点开/收起时正文会平滑展开，按钮有轻微浮起与按压回弹；系统开启「减少动态效果」时这些动画会自动关闭。

### 创作二级界面：切语言不丢已写内容，暗色不发灰（v2.682）

- 在日记、第一人称、双人对撞、世界线这四类创作界面里切中 / EN，标题、说明、字段名和侧栏建议会一起换语言；已经写进输入框的设定会原样保留，不会因为切语言被清空。
- 底部有工作台弹层盖着时，切语言不会顺手把弹层关掉。
- 这四类界面的分组底色会跟随当前主题：暗色/科技主题下不再出现浅色底配浅色字，字段名与说明都能看清。
- 生成配置栏不再整体悬浮吸底：英文长标签或素材较多时配置会很长，现在随页面正常滚动，不会盖住上方的创作说明。

### 结果页诊断：暗色下也读得清哪条是硬伤（v2.683）

- 出本后的诊断区（改稿尺子、质量评分卡、市场赛道、标题传播力、每集三问、开场四要素、资方视角等）现在会跟随主题换色：暗色/科技主题下分数不再用深绿深蓝、糊在深底上看不见，而是各自换成高对比的亮色。
- 每条诊断卡片带一条细色条和极轻的同色底：绿色=达标、蓝色=可用/中等、琥珀=需关注、朱砂=高风险，一屏多条时一眼能分出轻重。
- 浅色、护眼主题同样生效，颜色不会因为换主题而失真；系统开启「减少动态效果」不影响这套配色。

### 工具箱：首页看到什么，进来就是什么（v2.684）

- 首页「创作工具箱」和导航「工具箱」现在是同一套 7 件工具，顺序也一致：选题会、剧本围读、拆爆款、多版本去重体检、互动分支校验/起稿、剧本体检、打磨阶梯。
- 以前首页有选题会、围读，工具箱里却没有；工具箱有互动分支，首页预览里又找不到。现在两边都能直接点开对应面板。
- 工具箱里每张卡下方都有一句方法论提示（例如「一个选题要过四关：市场要、故事能、制作轻、观众爱」），新补的三张卡同样带提示。
- 英文界面下 7 张卡与副标题一起切换为英文，不再出现中英混排。

## 五、常见问题

**Q1：点「按当前创意递招」提示先写创意？**
独立递招必须有一句话创意，这是这条路径的唯一硬门槛。标签台不同，只有标签、没有补充创意也能递招。

**Q2：为什么每次结果一样？**
推荐是本地确定性规则，输入不变，结果就不变。想看到差异，改创意里的身份、反常事件或悬念方向，而不是反复点同一个按钮。

**Q3：我手动挑的卡，再点一次递招怎么没了？**
每次递招都会按当前输入重置为完整的新方案，这是为了避免新旧手法混杂。要保留手动组合，请先复制手法，或挑完直接出本。

**Q4：开篇审计为什么突然不见了？**
修改开篇、切换界面语言、或在标签台改标签/创意，都会让旧审计失效。重新递招即可恢复。

**Q5：标签台的回显为什么撤下了？**
增删标签、清空、修改补充创意、切语言都会撤下旧回显，防止旧手法被误用。点「按当前标签重新递招」重算。

**Q6：标签台和独立递招的数据会互相串吗？**
不会。独立递招上传的标签为空，标签台也不读递招面板的创意与开篇。两条路径各自独立，只有「选中的钩子与方法卡」是共用的一份。

**Q7：标签最多能选几个？**
手动最多 14 个；「智能随机一组」最多给 8 个。

**Q8：递招扣积分吗？**
不扣。递招与方法卡库是免费能力，只有进入实际生成才按各模式规则计费。

**Q9：中文界面能出英文剧本吗？**
可以。递招名称跟随界面语言，剧本语言由「输出语言」单独控制，两者互不影响。

**Q10：手机上在哪里点？**
顶栏「递招」与首页「标签创建」都能进。递招面板的输入区在窄屏会纵向排布，回显块的「重新递招」按钮会占满一行，方便单拇指操作。

**Q11：键盘能操作吗？**
可以。Tab 依次经过创意输入、开篇输入、递招按钮；方法卡与钩子按钮都可聚焦，回车/空格触发。焦点样式沿用全站统一描边。

**Q12：为什么标签台看不到开篇审计？**
标签台读取的是「当前打开作品」的正文，没有打开作品就没有可审计的开篇。想审计草稿，请用独立递招的「开篇试写」。

**Q13：结果页底部的「下一步」是什么？**
它是出本后的交接条：可以一键打开这部剧的分集与历史版本，或带着当前进度直接续写下一集。只有已经生成过正文才出现，不用它也不影响原有入口。

**Q14：点「继续写第 N 集」提示打开失败？**
多数是网络或登录态过期。点一次不会扣积分，重新登录或稍后重试即可；也可以先点「查看全部分集与版本」进作品详情，再用那里的「继续创作」。

## 六、标签台联动：六种状态与排障

标签台的回显不是「有或没有」两态，而是一台小状态机。认清当前处在哪一态，就知道该不该点重算。

| 状态 | 怎么进入 | 界面表现 | 你该做什么 |
| --- | --- | --- | --- |
| 正常态 | 随机一组 / 补齐维度 / 换一批 / 手动重新递招成功 | 实线边框，显示钩子与方法卡；有打开中的作品时多一行开篇审计 | 直接看结果，满意就出本 |
| 过期态 | 增删标签、清空标签、改补充创意、切换界面语言 | 虚线边框 + 「标签或创意刚改过」；旧钩子与方法卡撤下；右上角重算按钮仍可点 | 点一次「按当前标签重新递招」 |
| 空结果 | 标签被清空后仍点重算 | 提示先选至少一个标签，不生成任何手法 | 先随机一组或手动选标签 |
| 无开篇 | 当前没有打开任何作品 | 只显示钩子与方法卡，不出现开篇审计行 | 这不是故障；要审计草稿请走独立递招的开篇试写 |
| 重算中 | 点了重算，请求未返回 | 按钮置灰，旧结果暂时保留 | 等它返回，不要连点 |
| 重算失败 | 网络或登录态异常 | 保留上一次结果并提示失败，不扣积分 | 恢复网络/重新登录后再点一次 |

### 排障顺序（照这个顺序排查，最快）

1. **先看边框**：虚线=过期态，点重算；实线=正常态，问题不在回显。
2. **再看标签数**：0 个标签时重算必然空结果，先选标签。
3. **再看有没有打开作品**：没有作品就没有开篇审计，这是设计而非缺陷。
4. **最后看语言**：切过中/EN 后旧名称已过期，重算一次即可拿到当前语言的结果。
5. **仍然不对**：刷新页面。已选钩子与方法卡存在本机，刷新不会丢；丢的是未出本的临时回显。

### 与独立递招的边界（再确认一次）

- 标签台只读「标签 + 补充创意 + 当前打开作品正文」，不读递招面板里的一句话创意与开篇试写。
- 独立递招只读「一句话创意 + 开篇试写」，上传的标签为空，也不会在标签台生成回显。
- 两条路径共用同一份「已选钩子与方法卡」，所以你在任一路径挑的手法，另一条路径也认。

## 七、一条最短上手路线

1. 顶栏「递招」→ 写一句「女医生回乡，竟查到自己的死亡证明」。
2. 点「按当前创意递招」→ 看钩子与方法卡。
3. 点选两张最贴的卡 → 点「复制手法」留底。
4. 去「创作」点生成 → 自动匹配模式出本。
5. 出本后回「标签创建」→ 随机一组标签 → 看回显里的手法是否更贴 → 点「下一步：生成剧本」对比第二版。

两版都保留后，可以用「多版本去重体检」检查是否换汤不换药。
