# 统一创作规范（唯一事实源）

## 一、四阶段创作流程（禁止一键终稿，可停留在任意阶段打磨）
1. **梗概大纲**：产出 核心创意+人物小传（含隐性设定）+全剧大纲+分集梗概；阶段闸门：方向可被快速验证，不直接写台词
2. **初稿剧本**：产出 完整剧情与台词，故事闭环；阶段闸门：每集具备钩子-冲突-转折-留白节奏弧
3. **润色优化**：产出 节奏/台词/生活细节润色、去AI痕迹；阶段闸门：口语化、人设行为自洽、细节服务叙事
4. **精修定稿**：产出 按平台规则与制式（LIVE/AIGC）交付级剧本；阶段闸门：字数/版式/合规/去AI化全部达标

## 二、六维质量评分（逐集/全本均可，优化保留版本可对比）
- **人物**：人设饱满度、行为逻辑性、角色区分度、成长弧光
- **剧情**：节奏合理性、钩子有效性、反转惊艳度、逻辑自洽性、爽点密度
- **台词**：口语化程度、人物适配度、信息密度、情绪张力
- **市场**：题材适配度、平台匹配度、受众精准度、爆款潜力（缺真实榜单数据时标注 marketEstimated，不伪造）
- **格式**：格式规范性、字数精准度、拍摄/AIGC适配度
- **去AI化**：AI痕迹检测（分越低越像真人）

## 三、四层钩子体系（open/episode/scene/micro；微钩含动作/语言/氛围/情绪/信息差/伏笔六风味；默认系统布点，用户可指定层级；不是僵硬公式）
- **开篇钩（黄金三秒）**：第一帧/第一句就建立冲突、悬念、反差或绝境
- **集尾钩（追更钩）**：集尾抛未解问题或反转，强制点下一集
- **场钩（目标阻断/信息抛出/转场疑问）**：场末用目标阻断、信息抛出、转场疑问三处装置带入新冲突或新信息，拒绝平场过渡
- **微钩（动作/语言/氛围/情绪/信息差/伏笔六风味）**：句段级小悬念，维持单场内牵引；动作钩、氛围钩、语言钩是本层装置，不另立层

## 四、语言与文化适配
- 语种：zh、en、ja、ko、es、ar；选定输出语言后，标签体系、叙事习惯、价值观、爽点偏好、合规尺度随该地区重排；英文链路系统指令零中文，避免文化冲突；支持双语对照。

## 五、个性化外部信号（主动迎合但可关闭，地域表达必须准确）
- 实时时令事件（如5月高考、春节、开学季）：可做背景但需用户可关闭
- 在榜爆款题材（红果等国内外榜单）：优先向高热方向倾斜并由小南告知原因
- 用户地域（IP/主页）：人物方言、地域文化、生活道具贴合，不堆砌不错位
- 用户年龄/性别/受众画像：调整爽点类型、情感浓度与表达
- 用户历史修改动作与和小南的对话：沉淀偏好，反哺后续创作

## 六、人物表与成长弧一页纸（v2.63 交付规范）
- 人物卡只取自全局圣经（隐性设定/说话方式/弧光），出场集数、对手戏关系轴由成稿正文真实解析（场头人物+提及计数），主角五段成长阶段（受压起步→蓄力蛰伏→初次反击→连环升级→登顶收束）与节拍反转同源累计推进，确定性可复现；解析不到的人物关系绝不编造，无圣经时诚实标注“由成稿解析”。
- 固定装配顺序：情绪节奏图→逐集钩子地图→爽点-反转兑现链→人物表与成长弧→完整分集正文；一页纸最多 10 个有名角色、6 条对手戏轴，成长阶段线逐集全列。
